ML for Healthcare & Predictive Analytics

Interactive Streamlit app + Colab notebook for four supervised-learning projects: diabetes (KNN), breast cancer (KNN vs Logistic Regression), heart disease (neural network), autism screening (3 classifiers + diff view).

Live Streamlit app Open in Colab Notebook (.ipynb) GitHub repo

The four projects

Diabetes

KNN768 records

Missing-value zeros, scaling shootout, k-tuning curve, patient scorer with nearest-neighbour voters.

Breast cancer

KNN vs LogReg569 records

CV-chosen K, grid-searched Logistic Regression, ROC curves, record-by-record probability check.

Heart disease

13-8-14-1 network303 patients

Train the neural net live, watch loss/accuracy curves, score a new patient.

Autism screening

LR / Boosted / SVMROC-AUC

Cleaning + oversampling pipeline, overfitting check, per-model confusion matrices.

New: Compare page

Diff any two configs A vs B — diabetes preprocessing, breast-cancer models, heart training runs, autism models — with Δ (B − A) metric tables and side-by-side confusion matrices.

Run locally

pip install -r requirements.txt then streamlit run app.py. Multipage app: Home (app.py), shared code (ui_common.py, ml_core.py), pages in pages/.

Deploy your own copy

1. Push to a public repo named ml-healthcare-app. 2. Streamlit: share.streamlit.io → Create app → repo/branch main, file app.py → Deploy. 3. Pages: repo Settings → Pages → Deploy from branch main, folder / (root) — this index.html is served.
