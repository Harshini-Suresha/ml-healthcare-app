# Data files

| File | Used by | Status |
|---|---|---|
| `diabetes.csv` | Diabetes page, notebook | Included (768 records, 9 columns, public Pima diabetes dataset) |
| `heart.csv` | Heart disease page, notebook | Included (303 records, 13 attributes plus `target`, Cleveland heart-disease data in the common 14-column layout) |
| `autism_train.csv` | Autism page, notebook | **Add this file.** Kaggle "Autism Prediction" `train.csv` layout (`A1_Score` ... `A10_Score`, `age`, `gender`, `ethnicity`, `jaundice`, `austim`, `result`, `Class/ASD`, ...) |

Breast cancer uses the Wisconsin diagnostic dataset that ships with scikit-learn, so it needs no file.
If a file is missing, the app asks for an upload instead of failing.
